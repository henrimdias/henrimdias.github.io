# Henrique Dias — Personal Academic Website

This is a simple static website designed for GitHub Pages.

## Upload to GitHub

Upload **the contents of this folder** to the root of your repository:

`henrimdias/henrimdias.github.io`

The repository root should contain:

- `index.html`
- `research.html`
- `publications.html`
- `projects.html`
- `github.html`
- `cartoons.html`
- `contact.html`
- `assets/`

Do **not** upload only the ZIP file. GitHub Pages needs the actual files/folders.

## Important placeholders to update later

1. Replace `assets/images/profile.svg` with your real photo.
2. Add your professional email.
3. Add Google Scholar URL.
4. Add ORCID URL.
5. Add your CV PDF and link it.
6. Populate Publications.
7. Add cartoons / graphical abstracts.

## Updating the site later

Any time you edit these files and commit the changes to the `main` branch,
GitHub Pages will publish the new version automatically.
